# My Personal AI Coding Playbook

## 1. When I reach for AI first

Using GitHub Copilot in VS Code  for in-editor coding help while actively writing code.

## 2. When I do not reach for AI

When Copilot suggested overriding code I did not want changed, I rejected the suggestion and checked it myself instead of accepting it.

## 3. My non-negotiables

Always review an AI suggestion before applying it, never accept a change blind. Use GitHub (version control) as a safety net so any AI-suggested change can be inspected or reverted.

## 4. My review rules

Physically test something myself before accepting it as correct, rather than trusting an AI's explanation or claim on its own.

## 5. What I am still figuring out

Docker. I'm not yet familiar with it and want to understand it better, how it actually works, what happens when you build and run an image, and how it fits into getting an app running end to end.

## Decision Card

- **For a new feature I reach for: GitHub Copilot.** 

- **For a code review I reach for: Claude Code.** 

- **For debugging I reach for: GitHub Copilot.** 

- **For infrastructure I reach for: Claude Code.** 

- **I will never paste uncropped, full-desktop screenshots into an AI tool.** 

- **My one rule is: ask → inspect → run → test → refine.**
